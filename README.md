# مساحة الكاتب — منصة اختبار سحابية عربية

منصة ويب متعددة الحسابات للكاتب الفرد ضمن منظومة الذكاء الثقافي. نطاق التجربة: الرواية، القصة القصيرة، القصة الخاطفة، قصة الأطفال، والسيناريو. لا يشمل البحث العلمي أو الشعر.

## الوظائف المنفذة

- حساب مستقل لكل كاتب بدعوة لمرة واحدة، مع كلمات مرور مجزّأة وتوثيق جلسة في ملفات ارتباط محمية.
- مساحة كتابة حرة هي نقطة البداية؛ محرر فصول ومقاطع، ومحرر سيناريو بعناصر منظمة.
- بناء العمل والوقائع والشواهد، مع فصل تطابق الاقتباس عن إثبات صحة المعنى.
- نقطة «أين توقفت؟» قابلة للاستعادة؛ مدرب شخصي إرشادي بحسب جنس الكتابة.
- محادثة AI اختيارية: لا يبدأ الاتصال إلا بمفتاح على الخادم، ويوافق الكاتب لكل سؤال على مشاركة سياق محدد، ويمكن قبول اقتراحات التنظيم يدويًا فقط.
- تخزين عبر PostgreSQL في بيئة الإنتاج، ومنع تعارض نسخ المقطع/المشروع برقم مراجعة، وسجل مراجعات واستعادة.
- تصدير JSON واستيراد نسخة مشروع من المنصة، واستيراد/تصدير مجموعة Fountain الأساسية للسيناريو.
- واجهة عربية متجاوبة للحاسوب والهاتف، مع سياسة عدم الكتابة بدل المؤلف.

## التشغيل

للتجربة المحلية:

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
python scripts/create_invite.py
```

افتح `http://127.0.0.1:8000` في المتصفح وسجّل برمز الدعوة. احرص على عدم مشاركة ملف `writer.db` لأنه يحوي بيانات تجريبية نصية وحسابات.

للنشر على الإنترنت عبر Docker وPostgreSQL وHTTPS: اقرأ [دليل النشر](docs/النشر_على_الانترنت.md). انسخ `.env.example` إلى `.env` واضبط النطاق والأسرار ثم شغّل `docker compose up -d --build` على خادم موثوق.

**مهم:** الحزمة ليست موقعًا منشورًا على نطاق عام؛ نشرها يتطلب خادمًا ونطاقًا أو صلاحية الوصول إلى منصة استضافة وحماية قاعدة البيانات. لم تُجرَ اختبارات اتصال حقيقية بمفتاح OpenAI أو تشغيل PostgreSQL داخل Docker في هذه البيئة. لا تستدعِ هذه النسخة «إطلاقًا تجاريًا» قبل اختبار الخادم الفعلي والتعافي من الكوارث ومراجعة الامتثال.

## الدليل السريع للكاتب
1. أنشئ حسابًا برمز دعوة فريد.
2. أنشئ رواية أو قصة أو سيناريو من «مشروع جديد».
3. افتح «أفكار حرة» واكتب ما تريده مباشرة.
4. قسّم المخطوط إلى مقاطع أو مشاهد، واضغط حفظ أو انتظر حالة «تم الحفظ».
5. قبل التوقف، سجّل «أين توقفت؟» واحفظ الخطوة القادمة.
6. استخدم «مدربك الشخصي» لأسئلة مراجعة. إذا فعّل المشرف الذكاء الاصطناعي، اختر بعناية النصوص المسموح بمشاركتها.
7. حمّل نسخة احتياطية JSON بعد جلسات العمل المهمة.

## القيود الصريحة
- لا يوجد حاليًا تحقق دلالي مضمون للرواية أو السيناريو دون تفعيل وفحص AI.
- المدرّب المحلي قائم على أسئلة متخصصة، ولا يقيّم جودة العمل آليًا.
- استيراد Fountain يدعم صيغة أساسية محافظة ويرفض البنى المتقدمة أو الملتبسة؛ لا يدعم كل لهجات Fountain أو صيغة FDX.
- تسجيل الدعوات بديل مؤقت عن إدارة الهوية الكاملة؛ لا توجد استعادة كلمات مرور أو توثيق بريد.
- سجل المراجعات يحتفظ بنسخ الحفظ، وقد يكبر؛ يتطلب سياسة احتفاظ ومراقبة للسعة قبل الإطلاق المفتوح.
- لا ضمان بانعدام الأخطاء، أو موافقة المتاجر، أو صلاحية معالجة نصوص حساسة دون موافقة المستخدم وضوابط تشغيل مناسبة.
