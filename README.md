# مساحة الكاتب — Writer Space

منصة تجريبية عربية لمساعدة كاتب الرواية والقصة على **فهم مشروعه، تطويره، وحفظ تقدم عمله** دون توليد العمل الأدبي نيابة عنه. محرر السيناريو والأنواع الأخرى متاحان، لكن العمق النقدي المتخصص يحتاج اختبارات قبول مستقلة.

## حالة الإصدار
- **v4:** استرجاع أدلة من الفصول كاملة، نقد مع تصنيف وشاهدين، سجل التدريب الذاتي، Word وEPUB، بحث محلي داخل المخطوط، ونسخ مرجعية مستقلة.
- **حالة النموذج:** يتطلب مفتاح API مستقلًا؛ غياب المفتاح يعني أن النقد الذكي غير مفعل فعلًا، حتى لو نجحت اختبارات الخادم.
- **حالة المخطوطات الحقيقية:** غير معتمدة حتى اختبار النسخ والاستعادة الخارجية وحوكمة مزود النموذج.

## حالة الفروع
- `main`: النسخة المنشورة على Render حاليًا.
- **v3**: محرك أدبي متعدد الفصول وسجل نقد ومصادر وWord، بعد التحقق من النشر. تبقى مخطوطات المستخدمين الحقيقية خارج النسخة التجريبية حتى اعتماد النسخ الاحتياطي والخصوصية والنقد الفعلي.

## تجربة الكاتب
1. الدخول برمز دعوة شخصي، بعد عرض إشعار مراجعة الإدارة في البرنامج التجريبي.
2. إنشاء عمل أو فتح مشروع موجود؛ يمنع النظام التكرار العرضي للعناوين المتطابقة داخل الحساب والنوع.
3. كتابة الأفكار الحرة، مع أسئلة اختيارية للسؤال المركزي والرؤية والأثر المقصود.
4. عند تفعيل نموذج الذكاء الاصطناعي، يطلب الكاتب تحليل الأفكار ويوافق على إرسالها. تُعرض النتائج للاستعراض والاعتماد الانتقائي.
5. كتابة الفصول والمشاهد وحفظها واستعادتها (آخر ثلاث مراجعات سابقة).
6. إعداد ملخص مستقل لكل فصل: يدوي دائمًا، أو اقتراح ذكي بعد اتصال الخدمة.
7. استئناف الكتابة من الموضع المسجل تلقائيًا، مع إمكانية إضافة ملاحظة اختيارية عن الخطة التالية.
8. استيراد وتصدير JSON مع السجل النقدي، وتبادل المخطوط بصيغة Word DOCX، مع دعم Fountain للسيناريو.
9. «النقد الأدبي»: مراجعة مع شواهد واسترجاع جزئي بين الفصول وسجل ملاحظات يتحكم فيه الكاتب.
10. «الأعمال المشابهة»: بحث اختياري في بيانات Open Library فقط، وليس فحص انتحال أو مقارنة نصوص كاملة.

## تشغيل محلي
```bash
python -m pip install -r requirements.txt -r requirements-dev.txt
python -m pytest -q tests/test_acceptance.py tests/test_extended.py tests/test_publish_regression.py tests/test_release_regressions.py tests/test_pilot_invites.py tests/test_writer_intelligence.py tests/test_literary_core.py tests/test_narrative_v4.py tests/test_writer_tools.py
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

للدخول بدعوات الاختبار راجع `docs/تشغيل_تجربة_المدعوين.md` ومتغيرات `.env.example`. لا تضع أسرارًا في Git.

## متطلبات التحليل الذكي
- يمكن اختيار `WRITER_AI_PROVIDER` بين `openai` و`groq` و`openrouter`. يحتاج كل مزود إلى مفتاح خادم صالح، ولا تُستخدم أي خدمة دون إذن الكاتب.
- تستلزم `groq` نموذجًا من القائمة المجانية المسموحة، و`openrouter` نموذجًا محددًا يحمل `:free`. لا يوجد انتقال تلقائي لمزود مدفوع.
- مراجعة الصلاحيات والخصوصية والميزانية والحدود التشغيلية.
- عند غياب المفتاح، يظل الحفظ والتنظيم والملخص اليدوي والاستئناف متاحين؛ **لا يدعي النظام تقديم تحليل دلالي ذكي**.

## أمان الإصدار
لا تُعتمد ترقية على Render قبل اختبار PostgreSQL الفعلي، النسخ والاستعادة، جودة التحليل على نصوص مصطنعة، تسجيل الدخول، العرض على الهاتف، وحماية البيانات. تخزين Render المجاني يتطلب التحقق من تاريخ الصلاحية وممارسات الاستعادة قبل دعوة مؤلفين لإرسال مخطوطاتهم الحقيقية.
