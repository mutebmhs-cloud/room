# نشر منصة مساحة الكاتب للكتّاب المختبرين

## الحالة
هذا الإصدار منصة ويب تجريبية متعددة الحسابات وقابلة للاستضافة على خادم Docker. **ليس منشوراً بعد على عنوان عام**. يلزم خادم ونطاق DNS وربط HTTPS، واختبار استعادة قاعدة البيانات على الخادم الفعلي قبل دعوة كتّاب بمخطوطاتهم الحقيقية.

## المكونات
- الواجهة العربية: HTML/CSS/JavaScript دون أدوات بناء.
- الخادم: FastAPI + SQLAlchemy + PostgreSQL في الإنتاج.
- الحسابات: تسجيل بالدعوات، تجزئة كلمات مرور Argon2id، جلسات HttpOnly، رموز CSRF، عزل حسابات كل مؤلف.
- النصوص: حفظ متزامن عبر رقم مراجعة؛ يمنع التعارض الصامت؛ تاريخ نسخ واستعادة، وتصدير JSON للعمل.
- الذكاء الاصطناعي: اختياري عبر OpenAI Responses API. مفتاح المزود على الخادم فقط. مشاركة النصوص محددة ومسبوقة بموافقة الكاتب؛ لا يكتب أدباً نيابة عنه.

## إعداد خادم لينكس
1. اختر خادماً ببيئة تنفيذ Docker مع مساحة تخزين دائمة وبما يتوافق مع سياسة موقع بيانات المستخدمين. وجه سجل A للنطاق إلى عنوان IP للخادم.
2. ثبّت Docker Engine وDocker Compose Plugin. افتح TCP 80 و443 فقط. لا تعرض منفذ PostgreSQL.
3. انسخ مجلد المشروع إلى الخادم، ثم:

```bash
cp .env.example .env
python3 -c 'import secrets; print(secrets.token_urlsafe(48))'
```

4. عدل `.env`: ضع DOMAIN الفعلي، وAPP_SECRET عشوائي لا يقل عن 32 محرفاً وDB_PASSWORD قويًا لا يحتوي رموز URL الخاصة غير المشفرة (استخدم `secrets.token_urlsafe(32)`). احتفظ بملف `.env` خارج المستودع مع صلاحيات `chmod 600 .env`.
5. شغل:

```bash
docker compose up -d --build
docker compose ps
curl https://YOUR_DOMAIN/health
docker compose exec web python scripts/create_invite.py
```

6. انسخ رمز الدعوة إلى الكاتب المختبر عبر قناة خاصة. التسجيل غير مفتوح دون رمز فريد، ولا تشارك كلمة المرور أو مفتاح API.
7. فعل `OPENAI_API_KEY` فقط بعد تحديد سياسة الخصوصية والتكلفة والموقع وموافقة المشاركين؛ `docker compose up -d` لتطبيق التغيير.
8. لا تعرض الخدمة للجمهور المفتوح قبل مراجعة الاختبار الأمني والاختبارات الفعلية واستعادة النسخ الاحتياطية.

## النسخ الاحتياطي والاستعادة
- نفّذ `./scripts/backup.sh` بصورة دورية، وانقل نسخ القاعدة إلى مخزن مشفر منفصل عن خادم الإنتاج.
- اختبر الاستعادة في بيئة منفصلة بشكل دوري. نسخ JSON الفردية إضافة مفيدة وليست بديلًا عن نسخ PostgreSQL.
- لا تستخدم مجلد التطبيق أو قاعدة SQLite كحل تخزين دائم للإنتاج.
- احرص على سياسة احتفاظ، وفصل حسابات الصيانة، وتسجيل الأحداث دون محتوى المخطوطات.

## التشغيل في جهاز المطور
```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
python scripts/create_invite.py
```

افتح `http://127.0.0.1:8000` وأنشئ الحساب بالرمز. الوضع المحلي يستخدم SQLite للاختبار فقط.

## ما يجب استكماله قبل الإطلاق التجاري
- الانتقال من `create_all` إلى نظام ترحيل قاعدة بيانات بإصدارات معتمدة (Alembic) قبل تحديثات المخطط.
- اختبار اختراق مستقل وتحقق من خصائص عزل المستأجرين، وإضافة حد محاولات موزع Redis عند تعدد عمليات الخادم.
- التحقق من النسخ والاستعادة بعد انقطاع خادم فعلي والتعافي من فقد قاعدة البيانات.
- آلية رسمية لاستعادة كلمات المرور وتأكيد البريد وتسجيل الموافقات وإشعارات الخصوصية.
- تحديد الأساس النظامي للتعامل مع البيانات الشخصية وموقع المعالجة وفق النظام السعودي ومتطلبات التعاقد مع مزود الذكاء الاصطناعي.
- مراقبة الاستخدام والسعة والتكاليف والتنبيه إلى تعطل الخدمة.
- اختبار مؤلفين فعليين للرواية والقصة والسيناريو، وعدم ادعاء الفهم الأدبي الكامل قبل التقييم.

## خطوط حمراء
- لا ترسل مخطوطًا كاملاً تلقائياً إلى أي نموذج. المشاركة تتم عبر اختيارات صريحة في كل سؤال.
- مخرجات الذكاء الاصطناعي اقتراحات تنظيمية فقط؛ لا تُكتب النصوص الأدبية نيابة عن الكاتب.
- لا تعتمد على الاستيراد أو Fountain باعتبارهما بديلين عن النسخ الاحتياطي للقاعدة؛ Fountain تصدير أساسي فقط.
- لا تجعل حساب الكاتب أو المخطوط متاحاً من دون تسجيل دخول.

## نقل التجارب من الإصدار السادس
احتفظ بنسخة الإصدار السادس الأصلية كاملة. يمكن تحويل مشاريع الكتابة المدعومة من الملف المحلي إلى ملفات استيراد منفصلة:

```bash
python scripts/convert_v6_export.py old_v6_backup.json --outdir converted_v6
```

يعالج كل مشروع على حدة، ويرفض الأنواع غير المدعومة. يُرحّل النص الحالي والأفكار الحرة وبناء العمل والمقاطع والوقائع الممكن مطابقتها. **لا ينقل كل تاريخ المراجعات والمحادثات والتمارين القديمة**، لذا ينبغي حفظ ملف المصدر وفتحه في النسخة السابقة عند الحاجة. لا تعتبر عملية النقل ترقية دون فقد لجميع بيانات الإصدار السادس.
