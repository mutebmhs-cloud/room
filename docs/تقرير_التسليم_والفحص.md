# تقرير التسليم — منصة مساحة الكاتب السحابية

**التاريخ:** 30 أكتوبر 2026
**الحالة:** حزمة ويب متكاملة قابلة للنشر التقني واختبار دعوات محدود؛ **لم تُنشر على الإنترنت بعد**.

## ما أنجز

1. نظام حسابات منفصلة بدعوات لمرة واحدة، وتجزئة Argon2id، وجلسات HttpOnly، وحماية CSRF.
2. واجهة عربية RTL للمتصفح والهاتف مع خمسة أنماط كتابة: رواية، قصة قصيرة، قصة خاطفة، قصة أطفال، سيناريو.
3. كتابة حرة، وتنظيم بنيوي، ومقاطع وفصول، ومحرر سيناريو بعناصر معنونة.
4. ذاكرة وقائع مع شواهد حرفية وحالة تنبيه عند تغير المصدر، دون ادعاء صحتها الدلالية.
5. نقطة استئناف ترتبط بمقطع/مشهد، وبآخر قرار وخطوة وسؤال معلّق.
6. مدرب محلي إرشادي لكل نوع؛ لا يكتب النص ولا يدعي تقييم جودة تلقائي.
7. محادثة AI بتعليمات نوعية ومخرجات تنظيمية؛ لا ترسل نصًا إلا بما يختاره الكاتب، ولا تعتمد المخرجات دون موافقته.
8. قاعدة بيانات متعددة المستخدمين ومعاملات حفظ متفائلة (optimistic locking)، ومراجعات واستعادة.
9. نسخ JSON للعمل، واستيراد مستقل، وتبادل Fountain ضمن مجموعة فرعية محافظة، مع أداة تحويل مدروسة من V6.
10. ملفات النشر Docker وCompose وPostgreSQL وCaddy HTTPS مع إدارة الأسرار من بيئة الخادم.

## الاختبارات المنفذة

| المجموعة | النتيجة | نطاق الإثبات |
|---|---:|---|
| اختبارات FastAPI/المنطق | 7/7 ناجحة | عزل المستخدمين، CSRF، حفظ بإصدارات، استعادة، النص العربي، الشواهد، الاستيراد والتصدير، الرد الذكي بمحاكاة، حذف الحساب، Fountain |
| رحلات واجهة Chromium | 13/13 ناجحة | التسجيل، مشروع، نص حر، فصل، خطة، ذاكرة، مدرب، محادثة، استئناف، تصدير، إعادة فتح، سيناريو، هاتف |
| أخطاء JavaScript في المسارات المختبرة | 0 | تسجيل أخطاء الصفحة خلال اختبار المتصفح |
| اختبار Compose بنيويًا | ناجح | تحليل YAML لأقسام خدمات PostgreSQL وWeb وCaddy |

**مهم:** اختبار Chromium اعتمد واجهة محمّلة محليًا مرتبطة بنقاط API فعلية بواسطة جسر اختبار؛ بيئة المتصفح هنا تمنع التنقل المباشر إلى الخادم المحلي. لا يعد ذلك اختبارًا لنشر الشبكة العام أو HTTPS الحقيقي.

## حدود وموانع التوسع إلى الإطلاق العام

- الاتصال الحي بمزود الذكاء الاصطناعي لم يُنفّذ بمفتاح فعلي؛ لم يثبت مستوى التحليل الدلالي المتخصص.
- لم يُنفذ Docker على خادم عام أو اختبار PostgreSQL الحقيقي أو استعادة قاعدة البيانات من نسخة منفصلة في بيئة إنتاج.
- لا توجد إدارة متكاملة لاستعادة كلمات المرور أو تأكيد البريد؛ التسجيل بالدعوات فقط.
- يتطلب تحديث مخطط قاعدة البيانات في الإنتاج آلية ترحيل Alembic قبل أي ترقية لاحقة.
- يلزم مراجعة امتثال الخصوصية، والاحتفاظ بالبيانات، وأمن مزود النماذج، ومكان الاستضافة قبل تجربة مخطوطات سرية/حساسة.
- مدربنا المحلي يطرح أسئلة تحريرية، وليس ناقدًا آليًا يثبت جودة الأسلوب أو الحبكة. وFountain لا يغطي كل الصيغ المتقدمة.
- النسخ الفردية JSON لا تشمل سجل المحادثات ولا مراجعات كل نسخة؛ النسخ الكاملة لقاعدة PostgreSQL مطلوبة للتعافي.
- لا توجد اختبارات أحمال متعددة المستخدمين حقيقية على خادم إنتاج، أو اختبار اختراق احترافي.

## قرار الاعتماد

**مقبول للتجربة التقنية المغلقة بعد تنفيذ نشر تجريبي مع HTTPS، وإعداد نسخ احتياطية، والتحقق من استعادتها، وتفعيل سياسة الخصوصية.**

**غير معتمد بعد للإطلاق التجاري المفتوح أو ادعاء حماية كاملة للمخطوطات أو جودة دلالية مثبتة للمساعد.**

## شروط نشر أول تجربة

1. اختيار خادم ونطاق فرعي مناسبين؛ يفضل مناقشة متطلبات موقع تخزين البيانات ومعالجتها قبل استضافة أعمال كتّاب سعوديين.
2. HTTPS، ومتغيرات APP_SECRET وDB_PASSWORD وDOMAIN وقاعدة PostgreSQL دائمة.
3. توليد رمز دعوة منفصل لكل كاتب، وإظهار موافقة واضحة على سياسة معالجة البيانات.
4. اختبار استعادة قاعدة PostgreSQL في بيئة مستقلة، والتأكد من الحذف ومدة الاحتفاظ، ثم دعوة مجموعة صغيرة قبل زيادة الحمل.
5. تفعيل المفتاح الذكي عند الجاهزية فقط وقياس التكلفة والدقة والامتثال عبر سيناريوهات كاتب رواية وكاتب قصة وكاتب سيناريو.
